How the range is computed

Each member whose attribution window has closed contributes a holdout-weighted outcome, (A/π − (1−A)/(1−π)) · (Y − m(X)), where m predicts the outcome from the member's pre-period value using only members that matured on earlier days. That keeps the estimate unbiased under randomization while removing the variance the pre-period already explains. The range is an asymptotic confidence sequence (Waudby-Smith et al., Annals of Statistics 2024): it holds at every day simultaneously, so checking daily does not inflate false certifications. ROI is incremental value divided by Vi fees per treated member.
